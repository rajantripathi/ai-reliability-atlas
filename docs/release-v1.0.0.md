First public release of AI Reliability Atlas.

- Three historical case studies with original snapshots, checksums, recorded
  disagreements and explicit methodological limits.
- An editable BM25 retrieval example with fictional policies, before/after
  corpus rankings and downloadable per-term score traces.
- A deterministic policy sandbox with all 64 input combinations covered.
- Reproduction instructions, engineering notes and contextual notes for old
  heuristic metrics that must not be treated as validated answer quality.
